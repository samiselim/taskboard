TaskBoard {{ .Values.backend.image.tag }} deployed to namespace {{ .Release.Namespace }}.

Check the pods:
  kubectl -n {{ .Release.Namespace }} get pods,pvc

Try the API from your machine:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "taskboard.fullname" . }}-backend 8000:{{ .Values.backend.service.port }}
  curl http://localhost:8000/api/health

{{- if .Values.frontend.enabled }}
Open the frontend (it forwards /api to the backend inside the cluster):
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "taskboard.fullname" . }}-frontend 3000:{{ .Values.frontend.service.port }}
  open http://localhost:3000
{{- end }}

Run the built-in test:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
